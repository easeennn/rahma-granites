# Rahma Granites Homepage — Next.js Setup

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Useful commands:

```bash
npm run check
npm run build
npm start
```

This is a minimal Next.js App Router project. Tailwind CSS is installed and configured through PostCSS. The existing homepage component and visual styling are preserved exactly; the only changes are the project shell and runtime conversion from the previous Vite starter. The estimate form and room visualizer remain honest integration points until real endpoints are connected.
